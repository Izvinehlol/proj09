# Exercício 3 - Jogo de Adivinhação

## 📌 Descrição
O programa possui um número secreto entre 1 e 10.  
O usuário deve tentar adivinhar o número até acertar.  
Ao final, o sistema informa quantas tentativas foram necessárias.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Estrutura de repetição `while`
- Contador de tentativas
- Comparação de valores

## ✅ Resultado esperado
Exibir mensagem de parabéns e quantidade de tentativas realizadas.
