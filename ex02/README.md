# Exercício 2 - Soma com Confirmação

## 📌 Descrição
O programa solicita números inteiros ao usuário e realiza a soma dos valores digitados.  
Após cada número, o sistema pergunta se o usuário deseja inserir outro valor.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Estrutura de repetição `while`
- Acumulador de soma
- Validação de resposta

## ✅ Resultado esperado
Exibir a soma total dos números informados.
