# Exercício 1 - Validação de Senha

## 📌 Descrição
O programa solicita que o usuário digite uma senha.  
A senha correta está definida no código como "1234".  
O sistema continua pedindo a senha até que o valor correto seja informado.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Estrutura de repetição `do...while`
- Validação de dados

## ✅ Resultado esperado
Exibir a mensagem "Acesso Permitido" quando a senha correta for digitada.
