# Exercício 5 - Sistema de Cafeteria

## 📌 Descrição
O programa simula um sistema de pedidos de uma cafeteria.  
O usuário pode escolher produtos através de um menu interativo até finalizar o pedido.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Estrutura de repetição `do...while`
- Menu interativo
- Condicionais `if` e `else if`
- Acumulador de valores

## ✅ Resultado esperado
Exibir o valor total do pedido ao finalizar a compra.
