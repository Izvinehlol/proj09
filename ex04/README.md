# Exercício 4 - Validação de Cadastro

## 📌 Descrição
O programa solicita o nome de um produto.  
O cadastro só é aceito se o nome possuir no mínimo 3 caracteres.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Estrutura de repetição `do...while`
- Validação de quantidade de caracteres

## ✅ Resultado esperado
Cadastrar o produto somente quando o nome for válido.
